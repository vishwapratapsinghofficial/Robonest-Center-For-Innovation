# ROBONEST Center for Innovation website
Plain HTML, CSS and vanilla JS. Open the folder in VS Code and run **Live Server** on `index.html` (or open `index.html` directly).

- **Edit content:** `js/data.js` (courses, learning areas, email, map link).
- **Enable online enquiries:** set `CONFIG.FORM_ENDPOINT` in `js/data.js` to a form service or backend URL that accepts JSON. Until then the form shows a clear notice and a prefilled `mailto:` fallback, and never claims delivery.
- **Logo:** `assets/images/logo/robonest-logo.png` (trimmed copy of the supplied logo).
- **Not included yet:** photos, about/projects/gallery/contact pages, testimonials, social links, fees and schedules (nothing was supplied, so nothing was invented).
